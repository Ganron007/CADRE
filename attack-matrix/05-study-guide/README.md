# CADRE — Study Guide

Per-certification learning paths through the 62 CADRE walkthroughs. Each cert path lists which walkthroughs to complete in what order, with difficulty progression.

## How to Use

1. Pick your target cert from the table above
2. Open the corresponding `XX-<cert>-path.md`
3. Follow walkthroughs in the listed order (progression: easy → hard)
4. Each walkthrough references `04-automation/` scripts you can run
5. After completing a path, check coverage in `01-cert-matrix.md`
